# fm_comparison：Fama-MacBeth + Portfolio Sorting 指标可行性比较页面 — 设计文档

日期：2026-07-07（同日第二轮修订：打分引擎细化）
状态：已与 Chloe 确认（方案 B；打分规则经第二轮讨论修订）

## 1. 背景与目标

`D_analysis/output/fama_macbeth_results_reading/回归系数显著性/回归系数显著性_总表.xlsx`
汇总了多批次 Fama-MacBeth 回归与 portfolio sorting 结果（当前 6 个批次、22 个模型目录、
变量 FAC_rank_vol、参数网格 m3_n6 / m6_n3 / m6_n6 / m6_n12 / m12_n6）。
需要一个可视化页面，把新指标（如 6_市态条件一致性的 hs300/style/size/indvol 系列）与
之前阶段性决定采用的基准指标做四维度比较，判断哪些模型里的哪些因子有被用于选基的潜力，
并输出一份"fama-macbeth + portfolio_sorting 指标可行性排名"。

### 基准（现役指标）

- `fm_baseline_bottom33 × m3_n6`：bottom33 样本中历史排名波动率较高的基金；
- `fm_baseline_up × m6_n12`：top50 样本（对应模型目录 `fm_baseline_up`）中历史排名波动率较低的基金。

指标 2（m3_n3 窗口收益率未进前 50% 的剔除筛选）目前不在总表中，
待对应批次跑出后自动纳入，本期不阻塞。

## 2. 技术形态与位置

- **Streamlit 应用**，与现有 `I_Visualization/fama_macbeth_result_reading_app.py` 同栈。
- 目录：`I_Visualization/fm_comparison/`
  - `app.py` — Streamlit 页面
  - `data_loader.py` — 总表解析
  - `scoring.py` — 打分引擎（纯函数，可单测）
  - `config.py` — 默认权重、基准定义、路径常量
  - `output/` — 导出的可行性排名 xlsx
- 每次打开自动读最新总表；侧栏提供路径覆盖与"重新加载"按钮。

## 3. 数据层（data_loader.py）

总表五个 sheet 的共同格式是"同一 sheet 内多个批次块，表头行（来源批次…）重复出现"。
解析器按表头行切块，输出整洁 DataFrame：

| 输出表 | 来源 sheet | 关键列 |
|---|---|---|
| coverage | 模型比较样本覆盖 | 批次、模型目录、m、n、月份数、月均基金数、月份数×月均基金数、平均R²、平均调整R² |
| fm_coef | FM系数整理 | 批次、模型目录、变量、模型参数、coef、t、stars（解析 `-0.07*\n(t=-1.73)` 格式） |
| ps | PS_long_short_pvalue | 批次、模型目录、解释变量、模型参数、long_short、t_stat、p_value |
| corr_diag | 变量相关性诊断 | 批次、模型目录、唯一风险对列表（variable_1、variable_2、被标记次数、是否含核心变量）、VIF 风险变量列表（同结构）。解析单元格内嵌的 markdown 表格并按变量对去重 |

- **候选单元** = (模型目录 × m_n 组合)；**族** = 模型目录。
- 列头格式 `模型目录\n变量：XXX` 中的变量名要解析保留，未来多变量时自动扩展。
- 同一模型目录跨批次重复出现时，取批次号最大（最新）的记录并在页面标注来源批次。

## 4. 打分引擎（scoring.py）

总分 100 + 扣分项，所有阈值与权重集中在 `config.py`，侧栏可实时调整。

### 4.1 邻格定义

把 m、n 各自出现过的取值排序成两条轴（当前 m ∈ {3,6,12}、n ∈ {3,6,12}），
**邻格 = 恰好沿一条轴走一步的组合（曼哈顿距离 1）**。
例：m3_n3 ↔ m3_n6 是邻格（n 走一步）；m3_n3 ↔ m6_n6（对角）不是。
新参数组合（如指标 2 的 m3_n3）进入总表后，轴自动扩展、邻格关系自动生效。

### 4.2 四个维度

| 维度 | 满分 | 默认规则 |
|---|---|---|
| FM 显著性 | 40 | 按 \|t\| 分档：≥2.58 → 40；≥1.96 → 32；≥1.65 → 24；否则 0。系数符号在页面标注 |
| 邻格稳健性 | 10 | 按 4.1 定义取邻格；邻格中"与本格同号且 p<0.1"的比例 × 10；无邻格数据时记 0 并标注 |
| 多空显著性 | 30 | 基础分按 PS p_value：<0.01 → 30；<0.05 → 24；<0.1 → 18；<0.15 → 10；否则 0。再乘两个折扣系数（可叠乘）：(a) 方向冲突折扣——多空收益方向与 FM 系数方向不一致 → ×0.5（方向打架说明因子故事不自洽）；(b) 经济显著性折扣——月均多空收益 \|long_short\| < 0.3%/月 → ×0.8。两者都命中时 ×0.4。月均多空收益在页面加注；无 PS 记录记 0 并标注 |
| 回归质量 | 20 | 个体平均 R² 在全体候选中的分位数 × 12 ＋ 族平均 R² 在各族中的分位数 × 8（梯度化，避免临界点跳分） |

### 4.3 扣分项（只扣分，不剔除）

**样本量类**（候选层面）：

- 月份数 <60 → −5；<48 → −10（取更严档，不叠加）；
- 月份数×月均基金数 <6000 → −3；<3000 → −8（取更严档，不叠加）。

**共线性风险类**（族层面，作用于该族全部候选）：

数据事实：诊断 sheet 中同一风险对会在多个 m,n 参数组合里被重复标记，
因此先按 (variable_1, variable_2) **去重得唯一风险对**，再算**持续性系数
= 该对被标记次数 ÷ 该族参数组合数（上限 1）**。当前全部风险对均为
`Ctrl_fund_age × as_偏股混合型基金`（控制变量间），核心 FAC 变量未涉险，VIF 全部无风险。

- **Pearson 相关风险**：每组唯一风险对扣 −2（若该对含核心 FAC 变量 → −5），
  乘持续性系数，合计上限 −8。
  例：`fm_baseline_mid33` 1 组对、5 个参数组合中标记 3 次 → −2 × 0.6 = −1.2。
- **VIF 风险**：每个 VIF 风险变量扣 −4（核心 FAC 变量自身超标 → −8），
  乘持续性系数，合计上限 −12。
  VIF 是回归标准误被直接抬高的证据，严重程度按约 2 倍于 pearson 相关计。

### 配对比较（维度①样本切分）

样本切分不进分数，作为配对轴：

- `*_up` / `up_*` 系候选 ↔ 基准 `fm_baseline_up × m6_n12`
- `*_bottom33` 系候选 ↔ 基准 `fm_baseline_bottom33 × m3_n6`
- 其余（mid33、down 系等）不配对，仅参与总排名。

判定标注：

- 候选总分 > 对应基准总分 → 「可能可替代基准」badge；
- 领先 ≥ 10 分 → 「优先关注」badge。

## 5. 页面结构（app.py）

页面中心是"打擂台"式左右对照：**左边挑战者（新指标的整个族），右边守擂者（现役最优）**。
分数只作脚注参考，但计算过程必须在页面上可完整展开。三个 Tab + 侧栏：

### Tab1 擂台对比（默认主页）

- 选择器：挑战者 = 模型目录（族，如 `fm_baseline_indvol_bottom33`）；
  守擂者按配对规则自动带出（bottom33 系 → `fm_baseline_bottom33 × m3_n6`，
  up 系 → `fm_baseline_up × m6_n12`），可手动改。
- 中心左右两栏**结构对称**，两侧都显示完整 m×n 家族网格，守擂侧高亮现役格。
  每侧从上到下四个块，对应总表的 sheet 维度：
  1. **FM 系数网格**：行 m、列 n，格内 coef+stars+t，按 t 值着色——
     "指标附近的格子是否也显著"左右一眼可比；
  2. **覆盖与回归质量**：每个 m,n 的月份数、月均基金数、样本数、平均 R²；
     族平均 R² 及其跨族分位数放块标题行；
  3. **多空收益**：每个 m,n 的 long_short（月均）、t、p；
  4. **共线性诊断**：唯一风险对、持续性系数、VIF 风险。
- 挑战者侧每格相对守擂现役格标 优/平/劣 色点；每格右下角小字标注该候选总分（脚注式）。
- 页面底部"**分数计算明细**"expander：点选任一格后逐步展开——
  FM 分档（代入 t 值）、邻格比例（列出邻格清单与各自 p/符号）、
  PS 基础分 × 方向冲突系数 × 经济显著性系数、R² 两个分位数、逐项扣分——
  每一步显示公式与代入数值，让分数可被人工复算。
- 挑战者族中任一格总分 > 守擂现役格 → 该格标"可能可替代基准"badge；领先 ≥10 分 → "优先关注"。

### Tab2 可行性排行榜

全部候选按总分降序，列四维子分、扣分明细、badge、来源批次；
可按批次 / 样本层（up、bottom33、其他）/ m_n 参数筛选；基准行高亮；导出按钮在此页。

### Tab3 打分说明

当前生效的权重、分档公式、扣分规则、配对规则文字说明，随侧栏调整实时更新。

侧栏：四维权重与扣分阈值滑条、基准选择（默认上述两条，可改）、总表路径与重新加载。

## 6. 输出

排行榜页提供导出按钮，生成
`I_Visualization/fm_comparison/output/fm_ps_指标可行性排名_YYYYMMDD_HHMM.xlsx`，
含：排名总表、打分明细（各维子分与扣分逐项）、导出时刻生效的权重快照。

## 7. 测试

`tests/` 下对 `scoring.py` 与 `data_loader.py` 的关键函数做单元测试（合成小 DataFrame）：

- t 值字符串解析（含负号、星号 0–3 颗、空格变体）；
- 邻格集合的构造（角点、边点、中心点；m3_n3↔m3_n6 为邻格、对角不算；轴随新参数扩展）；
- 打分分档边界（t=1.96、p=0.05、月份数=60/48、样本数=6000/3000 等恰好落界）；
- PS 折扣系数：方向冲突 ×0.5、经济显著性 ×0.8、两者叠乘 ×0.4；
- 风险对去重与持续性系数（同一对标记多次只算一组；标记次数超过参数组合数时封顶 1）；
- 含核心 FAC 变量的风险对/VIF 变量按加重档扣分；
- 无 PS 记录 / 无邻格数据时的降级行为；
- 多批次重复模型目录取最新批次。

## 8. 已知限制

- 总表当前只有 FAC_rank_vol 一个变量；解析器兼容多变量，但指标 2（m3_n3）
  需等对应批次进总表后才会出现。
- R² 分位数打分依赖当前候选池构成，候选池扩大后同一模型分数可能变动（相对指标的固有性质）。
- 页面只读总表，不回溯 B_factors / D_analysis 原始输出；总表口径变了需同步改 data_loader。
