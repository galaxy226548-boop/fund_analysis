# fm_comparison：Fama-MacBeth + Portfolio Sorting 指标可行性比较页面 — 设计文档

日期：2026-07-07
状态：已与 Chloe 确认（方案 B）

## 1. 背景与目标

`D_analysis/output/fama_macbeth_results_reading/回归系数显著性/回归系数显著性_总表.xlsx`
汇总了多批次 Fama-MacBeth 回归与 portfolio sorting 结果（当前 6 个批次、22 个模型目录、
变量 FAC_rank_vol、参数网格 m3_n6 / m6_n3 / m6_n6 / m6_n12 / m12_n6）。
需要一个可视化页面，把新指标（如 6_市态条件一致性的 hs300/style/size/indvol 系列）与
之前阶段性决定采用的基准指标做四维度比较，判断哪些模型里的哪些因子有被用于选基的潜力，
并输出一份"fama-macbeth + portfolio_sorting 指标可行性排名"。

### 基准（现役指标）

- `fm_baseline_bottom33 × m3_n6`：bottom33 样本中历史排名波动率较高的基金；
- `fm_baseline_up × m6_n12`：top50 样本（对应模型目录 `fm_baseline_up`）中历史排名波动率较低的基金。

指标 2（m3_n3 窗口收益率未进前 50% 的剔除筛选）目前不在总表中，
待对应批次跑出后自动纳入，本期不阻塞。

## 2. 技术形态与位置

- **Streamlit 应用**，与现有 `I_Visualization/fama_macbeth_result_reading_app.py` 同栈。
- 目录：`I_Visualization/fm_comparison/`
  - `app.py` — Streamlit 页面
  - `data_loader.py` — 总表解析
  - `scoring.py` — 打分引擎（纯函数，可单测）
  - `config.py` — 默认权重、基准定义、路径常量
  - `output/` — 导出的可行性排名 xlsx
- 每次打开自动读最新总表；侧栏提供路径覆盖与"重新加载"按钮。

## 3. 数据层（data_loader.py）

总表五个 sheet 的共同格式是"同一 sheet 内多个批次块，表头行（来源批次…）重复出现"。
解析器按表头行切块，输出整洁 DataFrame：

| 输出表 | 来源 sheet | 关键列 |
|---|---|---|
| coverage | 模型比较样本覆盖 | 批次、模型目录、m、n、月份数、月均基金数、月份数×月均基金数、平均R²、平均调整R² |
| fm_coef | FM系数整理 | 批次、模型目录、变量、模型参数、coef、t、stars（解析 `-0.07*\n(t=-1.73)` 格式） |
| ps | PS_long_short_pvalue | 批次、模型目录、解释变量、模型参数、long_short、t_stat、p_value |
| corr_diag | 变量相关性诊断 | 批次、模型目录、相关性风险对数量、VIF风险有无 |

- **候选单元** = (模型目录 × m_n 组合)；**族** = 模型目录。
- 列头格式 `模型目录\n变量：XXX` 中的变量名要解析保留，未来多变量时自动扩展。
- 同一模型目录跨批次重复出现时，取批次号最大（最新）的记录并在页面标注来源批次。

## 4. 打分引擎（scoring.py）

总分 100 + 扣分项，所有阈值与权重集中在 `config.py`，侧栏可实时调整。

| 维度 | 满分 | 默认规则 |
|---|---|---|
| FM 显著性 | 40 | 按 \|t\| 分档：≥2.58 → 40；≥1.96 → 32；≥1.65 → 24；否则 0。系数符号在页面标注 |
| 邻格稳健性 | 10 | 邻格 = 参数网格上 m 或 n 相邻一步的组合（如 m6_n6 的邻格为 m3_n6/m6_n3/m6_n12/m12_n6）；邻格中"与本格同号且 p<0.1"的比例 × 10；无邻格数据时记 0 并标注 |
| 多空显著性 | 30 | PS p_value：<0.01 → 30；<0.05 → 24；<0.1 → 18；<0.15 → 10；否则 0。多空方向与 FM 系数方向不一致时不扣分但标警告；无 PS 记录记 0 并标注 |
| 回归质量 | 20 | 个体平均 R² 在全体候选中的分位数 × 12；族平均 R² 不低于"全族中位数 − 1 个跨族标准差"给 8 分，否则 0 |
| 扣分项 | — | 月份数 <60 → −5，<48 → −10（不叠加，取更严档）；月份数×月均基金数 <3000 → −5；该模型目录存在相关性风险对或 VIF 风险 → −5。只扣分，不剔除 |

### 配对比较（维度①样本切分）

样本切分不进分数，作为配对轴：

- `*_up` / `up_*` 系候选 ↔ 基准 `fm_baseline_up × m6_n12`
- `*_bottom33` 系候选 ↔ 基准 `fm_baseline_bottom33 × m3_n6`
- 其余（mid33、down 系等）不配对，仅参与总排名。

判定标注：

- 候选总分 > 对应基准总分 → 「可能可替代基准」badge；
- 领先 ≥ 10 分 → 「优先关注」badge。

## 5. 页面结构（app.py）

四个 Tab + 侧栏：

1. **可行性排行榜**：全部候选按总分降序，列四维子分、扣分明细、badge、来源批次；
   可按批次 / 样本层（up、bottom33、其他）/ m_n 参数筛选；基准行高亮。
2. **配对对比**：下拉选一个候选，与其基准并排展示四维明细
   （FM 系数+t、邻格小热力、R²/月份数/样本数、多空收益与 p 值），逐项标优/平/劣。
3. **m×n 显著性网格**：每个模型目录一张 t 值热力网格（行 m、列 n，格内显示 coef+stars），
   直观看"指标附近的格子是否也显著"。
4. **打分说明**：当前生效的权重、分档公式、扣分规则、配对规则文字说明，随侧栏调整实时更新。

侧栏：四维权重与扣分阈值滑条、基准选择（默认上述两条，可改）、总表路径与重新加载。

## 6. 输出

排行榜页提供导出按钮，生成
`I_Visualization/fm_comparison/output/fm_ps_指标可行性排名_YYYYMMDD_HHMM.xlsx`，
含：排名总表、打分明细（各维子分与扣分逐项）、导出时刻生效的权重快照。

## 7. 测试

`tests/` 下对 `scoring.py` 与 `data_loader.py` 的关键函数做单元测试（合成小 DataFrame）：

- t 值字符串解析（含负号、星号 0–3 颗、空格变体）；
- 邻格集合的构造（角点、边点、中心点）；
- 打分分档边界（t=1.96、p=0.05、月份数=60/48 等恰好落界）；
- 无 PS 记录 / 无邻格数据时的降级行为；
- 多批次重复模型目录取最新批次。

## 8. 已知限制

- 总表当前只有 FAC_rank_vol 一个变量；解析器兼容多变量，但指标 2（m3_n3）
  需等对应批次进总表后才会出现。
- R² 分位数打分依赖当前候选池构成，候选池扩大后同一模型分数可能变动（相对指标的固有性质）。
- 页面只读总表，不回溯 B_factors / D_analysis 原始输出；总表口径变了需同步改 data_loader。
